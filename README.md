# vodorod-11/homebrew-tap

[Homebrew](https://brew.sh) casks for my apps.

| Cask | App |
| --- | --- |
| `kopi` | [Kopi](https://github.com/vodorod-11/kopi): clipboard history for macOS, inspired by Ditto |

## Install

```sh
brew install --cask vodorod-11/tap/kopi
```

Installing by the full name (`vodorod-11/tap/kopi`) trusts just that cask, which Homebrew 6 and later
require for casks outside the official taps.

Update with `brew upgrade --cask kopi`, remove with `brew uninstall --cask kopi`
(add `--zap` to also delete Kopi's history and settings).

The casks are updated automatically when a new version of the app is released.
